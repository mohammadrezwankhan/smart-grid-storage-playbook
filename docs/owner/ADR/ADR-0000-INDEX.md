## Future ADR template

For a real decision, record: ID and title; status (proposed/accepted/superseded); actual date and responsible reviewer; problem and source revision; alternatives; selected behavior with units/limits; consequences and migration; verification evidence; links to superseded decisions.

Do not replace an observation with an “accepted” ADR merely because the source currently behaves that way. A control-priority, field-data or support-policy decision needs the appropriate owner's review. The [roadmap](../../../ROADMAP.md) supplies proposals, not approvals.
